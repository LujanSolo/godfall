{# --- MAP COORDINATES (Location only) --- Visible only when the category dropdown is set to "Location". JavaScript at the bottom toggles visibility. The picker is an interactive map: click anywhere on it to drop a pin marker. Two hidden form fields (lat, lng) get updated with the click coordinates as percentages of the map dimensions. This way, if we ever swap the map image for a different one (different resolution, different aspect ratio), the percentage coordinates still work. They're proportional, not absolute. Like targeting a thermal exhaust port — relative to the Death Star, not relative to a fixed point in the galaxy. #}
Map Position

Click anywhere on the map below to set this location's position. Click again to move it. The pin will appear on the world map for players to discover.

{# The picker container — relative positioning so we can absolute- position the pin marker inside it. cursor-crosshair is a UX touch: the cursor visually communicates "you can click here to place something." #}
{# The pin marker. Hidden by default. JavaScript shows it when there's a position set, and updates its top/left to match the coordinates. Translate-x/y by -50% so the pin's CENTER aligns with the click point, not its top-left corner. Without this, the pin would always sit slightly off from where the user actually clicked. #}
