{# MOBILE MENU JAVASCRIPT ===================== This is the small bit of vanilla JS needed to toggle the mobile menu. About 10 lines — a single blaster bolt, not an orbital strike. We're using plain JavaScript here because this is purely a local UI toggle — no server communication needed, so HTMX isn't the right tool. Knowing WHEN to use each tool is just as important as knowing HOW. Key concepts: - document.getElementById(): finds an HTML element by its id attribute. Like using the Force to locate a specific presence in a crowded room. - classList.toggle('hidden'): adds the "hidden" class if it's missing, or removes it if it's there. A light switch — on/off. - classList.contains('hidden'): checks whether an element currently has the "hidden" class. Like sensing whether a door is open or closed. #}
